# 国内军人做试管婴儿有什么优惠政策吗？

> 更新时间：2026-09-16 (UTC+8)

对于军人有不孕不育的夫妻想做试管的，他们所有的费用都是免费的。不过是需要满足夫妇双方或一方为现役军人，夫妇双方都有生育意愿，未采取避孕节育措施，同地居住1年以上或异地居住3年以上未能怀孕生育，且无影响怀孕生育的重大器质性疾病，经过军队或地方三级以上医院诊断为不孕不育症的育龄夫妇，才可以享受军人试管政策。

军人做试管婴儿的优惠政策

- 1. 经批准参加不孕不育诊治的军队育龄夫妇，在接受常规治疗和辅助生殖技术诊治期间发生的门诊与住院检查费、检验费、药品费、耗材费、手术费等全部免费；
- 2. 采取辅助生殖技术治疗的，免费限定在3个取卵周期以内；
- 3. 如果在诊治期间发现有重大器质性疾病的，按有关规定办理；
- 4. 调整了经费保障渠道，从申请专项诊治经费，转变为纳入据实核拨的军人及家属医疗费用保障。

如果已经已经进行过相关检查，可凭军队体系医院或地方三级以上医院的不孕不育症诊断证明材料，到各旅级单位计划生育管理部门填写《军队育龄夫妇不孕不育症诊治个人申请表》，由军级单位计划生育管理部门依据旅级单位上报的申请表和证明材料等进行审批。

经审批后可携带批准的《军队育龄夫妇不育不孕诊治个人申请表》、本人有效证件、军人保障卡、结婚证、生育证明或生育服务单、病历等相关资料，可以选择在家庭居住地、户籍所在地或本人工作地，就近选择一家已取得军队人类辅助生殖技术正式支行资质的医院进行诊治。

其实从2017年8月16日开始，对患不孕不育症的军队育龄夫妇已经实施了常态化诊治，现如今已经新增了诊治对象，由现役军人扩展到军队管理的退休干部和士官。目前取得军队人类辅助生殖技术正式运行资格的军队医疗机构已有30所，军队育龄夫妇不孕不育的可在这30所军队人类辅助生殖医学中心进行诊治。
